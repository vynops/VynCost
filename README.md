AI-powered recommendations. Zero cloud lock-in.[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)[![Next.js](https://img.shields.io/badge/Next.js-16-black)](https://nextjs.org)[![TypeScript](https://img.shields.io/badge/TypeScript-5-3178c6)](https://typescriptlang.org)> Part of the [VynOps](https://github.com/vynops) open-source platform engineering suite.</div>---## What is VynCost?VynCost is a production-grade FinOps dashboard for engineering teams running workloads across multiple cloud providers. Instead of logging into four separate billing consoles, reconciling spreadsheets, or waiting for month-end reports — VynCost gives you a single, real-time pane of glass for your entire cloud estate.**It is not a SaaS product.** Everything runs on your own infrastructure. No agents to install, no vendor accounts, no data leaving your network.---## Screenshots> Dashboard pages: Overview · Cost Explorer · Recommendations · Waste & Idle · Budgets & Alerts · Allocation · AI Copilot · Settings---## Features### Multi-Cloud Overview- Unified MTD spend across **AWS, GCP, Azure, OCI** in one number- Daily spend area chart — 30 days at a glance- Spend by provider bar chart — see distribution instantly- Top cost drivers table — the 8 services costing you the most right now- Live alert banners for cost spikes, idle resources, and budget breaches- Auto-refreshes every 30 seconds via SWR### Multi-Account per Provider- Connect **multiple accounts per cloud provider** — prod + staging + dev all tracked separately- Each account stores provider-specific credentials locally (never sent to any external service)- Accounts grouped by provider in Settings: add, test, or remove at any time- Status badges: `active`, `pending`, `error` — know at a glance if credentials are valid### Cost Explorer- Drill down by **service, provider, region, or account**- Date range selector: **7d / 30d / 90d**- Sortable table with: spend, % of total (inline bar), prior period comparison, trend indicator (↑↓)- Footer total row with period-over-period delta- Bar chart visualisation that updates with your groupBy/date selections### Rightsizing Recommendations- The core FinOps workflow: **current config + cost → recommended config + cost → savings**- Categories: **Rightsize · Idle/Shutdown · Reserved/Savings Plans · Spot Migration · Storage**- Per-recommendation: risk badge (`Low / Medium / High`), confidence %, category tag- One-click **copy CLI command** — the actual AWS/gcloud/az command to apply the change- **Mark as Applied** and **Dismiss** actions — track what you have acted on- Summary cards: open count, total savings/mo, annual potential- Filter by category and risk level simultaneously### Waste & Idle Detection- Surfaces **orphaned, unattached, and idle resources** across all connected accounts- Resource types: unattached EBS volumes, orphaned snapshots, idle EC2/Compute Engine instances, unused load balancers, stale GCS/S3 buckets, unattached reserved IPs, zombie databases- Shows: idle days (flagged red if > 30d), monthly cost, provider tag- **Dismiss** individual items once reviewed- Filter by provider- Summary: total waste count, monthly waste cost, daily burn rate, annual savings potential### Budgets & Alerts- Create budgets scoped to: **all spend, a specific provider, a region, or a service**- Budget periods: **monthly, quarterly, annual**- Set alert threshold (e.g. alert at 80%) — banners appear automatically when crossed- Optional **Slack webhook** per budget for push notifications- Color-coded progress bars: green (safe) → yellow (approaching threshold) → red (over budget)- Over-budget and near-threshold banners surfaced prominently at the top of the page### Cost Allocation / Showback- Team-by-team cost breakdown for **showback and chargeback** workflows- Tag coverage % — know which resources are properly tagged- Pie chart of spend distribution across teams- Side-by-side bar chart: this month vs prior month per team- Trend indicator per team with absolute spend and % of total### AI Copilot- Conversational FinOps assistant with **full cost context injection** — it sees your actual spend, waste, and recommendations- Powered by **Groq Llama 3.3 70B** for fast, intelligent responses- Ask in plain English: "What caused last week's spike?", "Which team is overspending?", "How much can I save this month?"- 5 quick-action chips for common questions- **Demo mode** — intelligent pre-loaded responses when no API key configured; seamlessly upgrades when GROQ_API_KEY is added- Full message history sent per request for context continuity### Settings & Account Management- **Cloud Accounts** section: grouped by provider, one-click add/test/remove per account- **Add Account modal**: step 1 = provider picker; step 2 = provider-specific credential form- **Test Connection** — validates credentials format and checks reachability before saving- **General Settings**: default date range, cost spike alert threshold, Slack webhook URL, waste auto-detect toggle- All settings saved to `data/settings.json` — survive restarts### Auth- Single-admin login with email + password- JWT session cookies via `jose` (HS256, 7-day expiry)- Credentials set in `.env.local` — never hardcoded- Middleware protects all dashboard routes and all API routes- Logout clears session cookie immediately---## Architecture```Browser (SWR polling, 30s intervals)    |    +-- /api/overview          <- MTD spend, alerts, top drivers, daily chart    +-- /api/explorer          <- Cost drill-down (groupBy + days)    +-- /api/recommendations   <- Rightsizing + optimisation opportunities    +-- /api/waste             <- Idle and orphaned resource list    +-- /api/budgets           <- Budget CRUD + progress computation    +-- /api/allocation        <- Team cost allocation + tag coverage    +-- /api/copilot           <- AI assistant (Groq + cost context injection)    +-- /api/accounts          <- Cloud account CRUD    +-- /api/accounts/[id]     <- Get / update / delete account    +-- /api/accounts/test     <- Test credentials per provider    +-- /api/settings          <- App settings CRUD    +-- /api/auth/login|logout <- JWT session managementVynCost Next.js Server    |    +-- Mock data engine       (realistic data when no accounts connected)    +-- Cloud provider APIs    (replaced as real integrations land per provider)```**Credential security model:**Cloud credentials never leave the VynCost server process in API responses.The `sanitize()` function in `lib/account-store.ts` strips all secret fields(awsSecretAccessKey, gcpServiceAccountJson, azureClientSecret, ociPrivateKey)before every response. Secrets are write-only from the browser's perspective.---## Tech Stack| Layer | Library | Purpose ||---|---|---|| Framework | [Next.js 16](https://nextjs.org) App Router | Pages, API routes, middleware || Language | TypeScript 5 | End-to-end type safety || Styling | [Tailwind CSS v4](https://tailwindcss.com) | Utility-first dark theme || Data fetching | [SWR](https://swr.vercel.app) | Real-time polling with auto-revalidation || Charts | [Recharts](https://recharts.org) | Area, bar, and pie charts || AI | [Groq SDK](https://groq.com) | Llama 3.3 70B for cost copilot || Auth | [jose](https://github.com/panva/jose) | JWT session cookies (HS256) || Storage | JSON files | Zero-dependency local persistence |No database. Demo mode uses a realistic mock data engine (`lib/mock-data.ts`) that generates:- 30 days of daily spend data across 4 providers- 7 rightsizing and optimisation recommendations with real CLI commands- 8 waste and idle resources with idle-day counts and monthly costs- Team allocation breakdown across 5 teams with tag coverage stats- AI Copilot with intelligent pre-loaded FinOps responses**Demo mode is automatic** — no configuration needed. As soon as you add a real cloud account and credentials are validated, real data replaces the mock data for that provider.---## Cloud Provider Setup### AWSVynCost needs read-only access to AWS Cost Explorer and billing data. Create a dedicated IAM user with this policy:```json{  "Version": "2012-10-17",  "Statement": [    {      "Effect": "Allow",      "Action": [        "ce:GetCostAndUsage",        "ce:GetRecommendations",        "ce:GetRightsizingRecommendation",        "ec2:DescribeInstances",        "ec2:DescribeVolumes",        "ec2:DescribeSnapshots",        "ec2:DescribeAddresses",        "rds:DescribeDBInstances",        "s3:ListAllMyBuckets"      ],      "Resource": "*"    }  ]}```**Required fields:** Account ID (12-digit) · Access Key ID (`AKIA...`) · Secret Access Key · Default Region (e.g. `eu-west-1`)---### GCPCreate a **Service Account** with the `Billing Account Viewer` and `Cloud Asset Viewer` roles. Download the JSON key file.**Required fields:** Project ID · Service Account Email · Service Account JSON (paste the full key file contents)---### AzureCreate an **App Registration** (Service Principal) in Azure AD. Assign the `Cost Management Reader` role at the subscription scope.**Required fields:** Subscription ID · Tenant ID · Client ID (Application ID) · Client Secret---### OCICreate an API signing key pair and add the public key to your OCI user profile. Grant the user `read` access to the Cost & Usage reports.**Required fields:** Tenancy OCID · User OCID · Fingerprint · Private Key (PEM format) · Region (e.g. `eu-frankfurt-1`)---## Recommendations — Current to OptimisedThe core workflow: VynCost shows you exactly what you are running, what it costs, and what you should switch to — with the exact CLI command to do it.Example recommendation card:```[EC2 Rightsizing]                                    Risk: LOW   Confidence: 87%prod-app-server-01  (us-east-1a)Current:    m5.2xlarge    ->   $289.20/mo    CPU avg: 4.2%,  RAM avg: 18%Optimised:  m5.large      ->    $83.14/moSavings: $206.06/mo  ($2,472/yr)              Category: RightsizeApply command (copy):  aws ec2 modify-instance-attribute \    --instance-id i-0abc123def456789 \    --instance-type '{"Value": "m5.large"}'  [Mark as Applied]  [Dismiss]```---## API ReferenceAll endpoints require authentication (session cookie). Secure the machine VynCost runs on.- **Credential sanitisation** — the `sanitize()` function in `lib/account-store.ts` strips all secret fields before any API response. Credentials are write-only from the browser perspective.- **`VYNCOST_SECRET`** must be a random 32+ byte value in production. Do not reuse across deployments.- All API routes are protected by JWT session middleware. There is no anonymous API access.- Use HTTPS (nginx + Let's Encrypt) in production — credentials are in transit only over TLS.- For AWS, use an IAM user with **read-only billing permissions only** — never use root credentials or admin keys.---## Roadmap### v0.2 — Real Cloud Integration- [ ] AWS Cost Explorer API integration (real billing data)- [ ] GCP Billing Export / BigQuery integration- [ ] Azure Cost Management API integration- [ ] OCI Usage Reports API integration- [ ] Scheduled data sync (cron, configurable interval)### v0.3 — Alerting & Automation- [ ] Slack/webhook alerts: budget threshold, cost spike, new waste detected- [ ] Email alerts via SMTP- [ ] Alert history log with acknowledgement- [ ] Auto-apply low-risk recommendations (with approval flow)### v0.4 — Advanced FinOps- [ ] Reserved Instance / Savings Plan purchase advisor- [ ] Anomaly detection (statistical spike detection per service)- [ ] Custom tag-based allocation rules (YAML config)- [ ] Multi-user support with team-scoped views- [ ] CSV / PDF cost report export### Future- [ ] Terraform cost estimation (pre-apply plan diffing)- [ ] Kubernetes cost allocation (container-level, via VynOps)- [ ] Prometheus metrics export (`/metrics`)- [ ] SSO / OIDC support---## Contributing1.
